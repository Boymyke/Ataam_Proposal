Discovery summary

This is a full refresh, not a cosmetic reskin.

The project is about creating a new digital expression for AWJAI while protecting the organisation’s existing credibility, content and WordPress publishing workflow.

01

The direction has already been explored.

Three homepage concepts were created before this proposal. During the review meeting, sections were compared, removed, retained and combined. The paid engagement begins from that informed direction rather than starting with guesswork.

02

The refresh needs to feel like one brand.

The final website will unify typography, colour application, imagery, spacing, components, editorial presentation and interaction patterns so visitors experience one consistent AWJAI identity across every page.

03

The website must make action easier.

People should quickly understand AWJAI’s work, see measurable impact, access legal and public-education resources, report a violation, get help, read current updates and find clear ways to engage with the organisation.

04

WordPress remains the operational foundation.

The new experience will be rebuilt around AWJAI’s existing WordPress environment so the team keeps a familiar publishing workflow while gaining stronger templates, cleaner structure and a more maintainable front end.

Project scope

A complete website refresh from direction to launch.

The engagement covers the strategy, visual refresh, page system, WordPress implementation, content restructuring and launch work needed to turn the selected concept direction into a complete production website.

01

Concept synthesis & direction

Translate the three concepts and review meeting decisions into a final production brief, section hierarchy and approved design direction.

02

Digital brand refresh

Refine the website’s visual language — typography, colour application, spacing, imagery, component styling and editorial rhythm — into one consistent system.

03

UX, navigation & page architecture

Restructure how visitors move through About, Work, Impact, Priority Areas, Resources, News, Get Involved, Contact and Report a Violation journeys.

04

Responsive UI system

Design production-ready desktop, tablet and mobile components, templates, states and interactions with clear accessibility and usability standards.

05

Full WordPress rebuild

Implement the approved experience in WordPress using reusable sections, maintainable templates and content structures suited to AWJAI’s ongoing publishing needs.

06

Content, SEO, QA & launch

Restructure priority content, improve publishing presentation, configure core SEO foundations, test forms and responsive behaviour, then deploy and hand over.
